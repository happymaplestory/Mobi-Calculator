# test.html 요구사항 ## 역할 프로젝트의 실제 기능 개발에 앞서 웹페이지의 동작과 UI를 외부 환경에서 확인하기 위한 개발 테스트 페이지입니다. GitHub Pages를 통해 외부에서 접근할 수 있으며, 다른 실제 페이지에 기능을 반영하기 전에 HTML, CSS, JavaScript 및 브라우저 동작을 테스트하는 용도로 지속적으로 유지합니다. ## 기본 구성 - 페이지 제목은 `마비노기 모바일 계산기 개발 테스트`로 표시합니다. - 페이지 본문에는 이 페이지가 개발 테스트 환경임을 명시합니다. - 현재 테스트 항목으로 `pages_js/runes-data.js`의 룬 데이터를 표로 표시합니다. - ES 모듈에서 `RUNES`를 가져오고 `RUNES.items`를 순회하여 각 룬을 한 행씩 표시합니다. - 표의 열 제목은 `부위`, `이름`으로 표시하고 각각 룬 데이터의 `slot`, `name` 값을 표시합니다. 등급 텍스트는 표시하지 않고 행의 배경색과 테두리 색상으로만 구분합니다. `desc`는 표에 직접 노출하지 않고 행 클릭 시 팝업으로 표시합니다. `장신구` 슬롯 데이터는 `runes-data.js`에서 제외합니다. - 표 위에는 최대 너비 350px 안에서 다섯 개의 등급 및 슬롯 필터 스위치를 같은 너비로 배치하고, 그 아래에 검색창과 하나의 정렬 전환 버튼을 표시합니다. 등급 필터는 `신화`, `전설`, 슬롯 필터는 `무기`, `방어구`, `엠블럼`이며 모두 기본 활성화 상태입니다. 각 필터 그룹에서 비활성화된 항목은 결과에서 제외됩니다. - 검색은 룬 이름과 설명을 대상으로 하며, 검색 결과는 이름 가나다순으로 정렬할 수 있습니다. 정렬 버튼 하나로 오름차순/내림차순을 전환하며 기본값은 가나다순입니다. - 페이지당 10개를 표시하고, 필터링된 검색 결과가 10개를 초과할 때만 페이지 전환을 표시합니다. 좌우 화살표는 현재 페이지에서 한 페이지씩 이동하며, 양 끝은 첫 페이지 번호와 마지막 페이지 번호로 표시합니다. 좌우 화살표는 현재 페이지에서 한 페이지씩 이동하며, 양 끝은 첫 페이지 번호와 마지막 페이지 번호로 표시합니다. - `부위` 열은 세 글자 슬롯 이름이 줄바꿈 없이 표시되는 60px 고정 너비를 사용하고, `이름` 열은 남은 너비를 사용합니다. - 등급이 `전설`인 행은 옅은 오렌지색 계열 배경과 테두리를, `신화`인 행은 옅은 개나리색 계열 배경과 테두리를 사용합니다. - 룬 행을 클릭하거나 키보드에서 Enter/Space를 누르면 해당 룬의 이름, 슬롯 및 설명을 사용자 정의 스타일의 팝업으로 표시합니다. 팝업은 닫기 버튼, 바깥 영역 클릭 및 Escape 키로 닫을 수 있습니다. - 설명에 포함된 줄바꿈은 팝업 안에서 유지합니다. - 목록 제목과 검색 결과 수 표시는 생략합니다. - 화면 너비 480px/481px를 기준으로 스타일을 분기하는 미디어 쿼리는 사용하지 않습니다. 필터, 검색·정렬 영역, 표 및 설명 팝업은 동일한 CSS 규칙을 사용합니다. - 룬 검색·필터 영역(`.rune-controls`), 결과 표(`.rune-table-wrap`), 페이지네이션을 350×750px 테스트 박스 안에 배치합니다. 박스 너비는 좁은 화면에서 부모 너비를 넘지 않도록 제한하고, 내부 콘텐츠는 스크롤할 수 있지만 스크롤바는 표시하지 않습니다. - 검색·필터 변경으로 페이지네이션 항목이 생성되거나 소멸할 때 해당 항목에는 260ms 페이드 인/아웃만 적용하며 항목 자체의 이동·확대·축소는 적용하지 않습니다. 새 항목이 추가되어 기존 페이지네이션 항목의 가로 위치가 달라지는 경우, 기존 항목들도 이전 위치에서 새 위치까지 260ms 동안 부드럽게 이동합니다. 페이지네이션 영역의 높이와 여백 변화로 위치가 달라지는 주변 요소 역시 260ms 동안 부드럽게 이동합니다. 운영체제의 동작 줄이기 설정을 존중합니다. - 이 표와 팝업은 테스트용 표시이며 실제 계산기 기능과 연결하지 않습니다. ## 사용 원칙 - 다른 실제 페이지에 기능을 반영하기 전에 필요한 동작을 이 페이지에서 먼저 확인할 수 있습니다. - 테스트 대상에 따라 필요한 테스트용 코드와 데이터를 추가할 수 있습니다. - 특정 테스트가 종료되면 해당 테스트에만 사용한 기능은 제거하여 다음 개발 작업을 위한 테스트 환경으로 사용할 수 있도록 유지합니다. - 실제 페이지의 기능이나 요구사항을 이 파일에 고정해서 문서화하지 않습니다. - 실제 페이지에 반영된 기능의 상세 요구사항은 해당 페이지의 `README_[file_name]`에서 관리합니다. - 정렬 전환 버튼은 텍스트 기호 대신 SVG 픽토그램을 사용합니다. 정렬 방향에 따라 화살표가 아래/위로 바뀌며, 이전/다음 페이지 버튼도 `<`, `>` 텍스트 대신 SVG 화살표 픽토그램을 사용합니다. 버튼의 접근성 이름과 기존 동작은 유지합니다. - 정렬 아이콘은 가나다순의 SVG 픽토그램 전체를 역순 정렬에서 세로 반전해 화살표 방향과 막대 길이 순서를 함께 뒤집으며, 화살표가 막대와 겹치지 않도록 합니다. 이전/다음 페이지 SVG 화살표는 버튼 내부에서 가로·세로 모두 중앙 정렬합니다.
