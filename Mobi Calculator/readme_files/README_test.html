# test.html 요구사항 ## 역할 프로젝트의 실제 기능 개발에 앞서 웹페이지의 동작과 UI를 외부 환경에서 확인하기 위한 개발 테스트 페이지입니다. GitHub Pages를 통해 외부에서 접근할 수 있으며, 다른 실제 페이지에 기능을 반영하기 전에 HTML, CSS, JavaScript 및 브라우저 동작을 테스트하는 용도로 지속적으로 유지합니다. ## 기본 구성 현재 페이지에는 테스트 환경임을 알리는 기본 안내만 제공합니다. - 페이지 제목은 `마비노기 모바일 계산기 개발 테스트`로 표시합니다. - 페이지 본문에는 이 페이지가 개발 테스트 환경임을 명시합니다. - 특정 계산 기능, 입력 UI, 데이터 목록, 드래그 앤 드롭 등의 실제 기능은 기본 구성에 포함하지 않습니다. - 특정 테스트가 필요할 때 해당 개발 작업에 필요한 HTML, CSS, JavaScript를 이 페이지에 추가하여 테스트합니다. ## 사용 원칙 - 다른 실제 페이지에 기능을 반영하기 전에 필요한 동작을 이 페이지에서 먼저 확인할 수 있습니다. - 테스트 대상에 따라 필요한 테스트용 코드와 데이터를 추가할 수 있습니다. - 특정 테스트가 종료되면 해당 테스트에만 사용한 기능은 제거하여 다음 개발 작업을 위한 테스트 환경으로 사용할 수 있도록 유지합니다. - 실제 페이지의 기능이나 요구사항을 이 파일에 고정해서 문서화하지 않습니다. - 실제 페이지에 반영된 기능의 상세 요구사항은 해당 페이지의 `README_[file_name]`에서 관리합니다.
