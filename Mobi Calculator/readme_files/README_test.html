# test.html 요구사항 ## 역할 프로젝트의 실제 기능 개발에 앞서 웹페이지의 동작과 UI를 외부 환경에서 확인하기 위한 개발 테스트 페이지입니다. GitHub Pages를 통해 외부에서 접근할 수 있으며, 다른 실제 페이지에 기능을 반영하기 전에 HTML, CSS, JavaScript 및 브라우저 동작을 테스트하는 용도로 지속적으로 유지합니다. ## 기본 구성 - 페이지 제목은 `마비노기 모바일 계산기 개발 테스트`로 표시합니다. - 페이지 본문에는 이 페이지가 개발 테스트 환경임을 명시합니다. - 현재 테스트 항목으로 `pages_js/runes-data.js`의 룬 데이터를 표로 표시합니다. - ES 모듈에서 `RUNES`를 가져오고 `RUNES.items`를 순회하여 각 룬을 한 행씩 표시합니다. - 표에는 `slot`, `name`을 순서대로 표시합니다. 등급은 행의 배경색과 테두리 색상으로만 구분하며 등급 텍스트는 표시하지 않습니다. `desc`는 표에 직접 노출하지 않고 행을 클릭했을 때 설명 팝업으로 표시합니다. - `slot` 열은 세 글자 슬롯 이름이 줄바꿈 없이 표시되는 60px 고정 너비를 사용하고, `name` 열은 남은 너비를 사용합니다. - 등급이 `전설`인 행은 옅은 오렌지색 계열 배경과 테두리를, `신화`인 행은 옅은 개나리색 계열 배경과 테두리를 사용합니다. - 룬 행을 클릭하거나 키보드에서 Enter/Space를 누르면 해당 룬의 이름, 슬롯 및 설명을 사용자 정의 스타일의 팝업으로 표시합니다. 팝업은 닫기 버튼, 바깥 영역 클릭 및 Escape 키로 닫을 수 있습니다. - 설명에 포함된 줄바꿈은 팝업 안에서 유지합니다. - 표의 행 수는 데이터의 `RUNES.items.length`를 따르며, 총 항목 수를 함께 표시합니다. - 이 표와 팝업은 테스트용 표시이며 실제 계산기 기능과 연결하지 않습니다. ## 사용 원칙 - 다른 실제 페이지에 기능을 반영하기 전에 필요한 동작을 이 페이지에서 먼저 확인할 수 있습니다. - 테스트 대상에 따라 필요한 테스트용 코드와 데이터를 추가할 수 있습니다. - 특정 테스트가 종료되면 해당 테스트에만 사용한 기능은 제거하여 다음 개발 작업을 위한 테스트 환경으로 사용할 수 있도록 유지합니다. - 실제 페이지의 기능이나 요구사항을 이 파일에 고정해서 문서화하지 않습니다. - 실제 페이지에 반영된 기능의 상세 요구사항은 해당 페이지의 `README_[file_name]`에서 관리합니다.
