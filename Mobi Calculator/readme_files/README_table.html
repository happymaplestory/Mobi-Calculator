# table.html 요구사항 ## 역할 마비노기 모바일 계산기의 위치 기반 게임 데이터 입력 테이블을 표시합니다. 데이터 분류는 `pages_js/data-model.js`에서 관리하고, 화면 생성은 `pages_js/table.js`, 시각적 표현은 `pages_css/table.css`에서 관리합니다. ## 화면 구성 - 위치 Table의 각 항목을 하나의 category-column으로 표시합니다. - category-column은 위치 ID 오름차순으로 배치합니다. - 각 category-column의 제목은 위치 Table의 `name` 값을 사용합니다. - 각 category-group에는 위치 항목이 참조하는 속성 그룹에 속한 구분 Table 항목을 행으로 표시합니다. - 속성 Table의 `name` 값은 화면에 표시하지 않습니다. - 기본 행은 첫 번째 열에 구분 Table의 `name`, 두 번째 열에 `+`, 세 번째 열에 사용자 입력 영역을 배치합니다. - 기본 행의 두 번째 열은 구분 Table의 적용 형식과 관계없이 `+`로 고정합니다. - ID 7000과 8000은 별도 지시가 있을 때까지 제목만 표시하며, 행 추가 기능도 표시하지 않습니다. - ID 1000~6000의 각 테이블 하단에는 행 추가 버튼을 표시합니다. - 추가 행에는 구분 이름 텍스트 입력, 적용 형식 선택 목록, 값 텍스트 입력, 행 삭제 버튼을 표시합니다. - 추가 행의 적용 형식 선택 목록은 적용 Table의 모든 항목을 이름으로 표시하며, 선택값은 적용 항목 ID를 사용합니다. - 추가 행의 삭제 버튼은 해당 추가 행만 제거합니다. 삭제 버튼은 행 높이를 기준으로 세로 중앙에 정렬합니다. - 기존 행은 이동할 수 없으며, 사용자가 추가한 행만 드래그할 수 있습니다. 추가 행 왼쪽의 드래그 핸들로 이동을 시작하며, 입력 필드와 선택 목록은 일반적으로 편집할 수 있어야 합니다. - 행은 마우스로 끌어 같은 위치 안에서 순서를 변경할 수 있습니다. 드래그 중 원본 행은 흐리게 표시하고, 이동 위치에는 placeholder를 표시하며, 드래그 중인 행은 포인터를 따라 표시합니다. placeholder 위치가 바뀔 때 주변 추가 행은 부드럽게 밀려나는 애니메이션을 표시합니다. - 다른 위치로 행을 옮길 때는 확인 메시지를 표시합니다. 취소하면 원래 위치로 되돌리고, 확인하면 입력값을 유지한 채 대상 위치로 이동합니다. - 입력 필드와 버튼을 조작할 때는 드래그가 시작되지 않아야 합니다. - 화면 너비가 바뀌어도 category-column의 배치 순서와 열 구성을 자동으로 재계산하지 않습니다. 좁은 화면에서는 가로 스크롤로 확인합니다. ## 입력 영역 - 값 입력은 숫자뿐 아니라 `%` 및 필요한 텍스트를 입력할 수 있도록 `input type="text"`를 사용합니다. - 추가 행의 구분 이름은 텍스트로 직접 입력할 수 있어야 합니다. - 추가 행의 적용 형식은 선택 목록에서 고를 수 있어야 합니다. - 입력값과 구분 이름은 텍스트 선택 및 복사가 가능해야 합니다. ## 테마와 hover - 행 hover 배경색은 단일 회색이 아니라 해당 category-card의 제목 색상과 어울리는 색상 계열을 사용합니다. - 추가 및 삭제 버튼의 테두리와 hover 색상은 해당 category-card 테마를 따릅니다. ## 데이터 참조 규칙 - `table.js`는 `data-model.js`의 `MOBI_DATA_MODEL`을 참조합니다. - 위치 항목은 `locationTable`의 ID, 이름, `attributeGroups`를 사용합니다. - 구분 항목은 `sectionTable`의 `id`, `group`, `name`을 사용합니다. - 행은 위치 항목이 참조하는 속성 그룹에 해당하는 구분 항목을 모아 구분 ID 오름차순으로 표시합니다. - 추가 행의 적용 목록은 `applicationTable`에서 생성합니다. - 입력값을 계산에 사용하거나 JSON으로 저장하는 기능은 이 변경에 포함되지 않습니다. ## 관련 파일 - `table.html`: 데이터 모델과 화면 스크립트 연결 - `pages_js/data-model.js`: 위치·속성·구분·적용 데이터 정의 - `pages_js/table.js`: 위치별 열과 행 생성 및 추가/삭제 동작 - `pages_css/table.css`: 레이아웃 및 시각적 표현
