# table.html 요구사항 ## 역할 및 파일 관계 - 위치 기반 게임 데이터 입력 화면의 HTML 구조를 정의합니다. - 데이터 분류는 `pages_js/data-model.js`, 테이블 생성 및 상호작용은 `pages_js/table.js`, 저장/불러오기는 `pages_js/storage-manager.js`, 시각적 표현은 `pages_css/table.css`에서 관리합니다. - `table.html`은 데이터 모델, 테이블 스크립트, 저장/불러오기 스크립트를 순서대로 불러오며, 테마 상태를 쿠키와 페이지에 연결합니다. ## 테이블 구성 - 위치 Table 항목을 ID 오름차순으로 category-column에 표시하고, 제목은 위치 Table의 `name`을 사용합니다. - 각 열에는 해당 위치가 참조하는 속성 그룹에 속한 구분 Table 항목을 ID 오름차순으로 표시합니다. 속성 Table의 `name`은 화면에 표시하지 않습니다. - 기본 행은 구분 이름, 고정 표시 `+`, 값 입력 영역으로 구성합니다. - 위치 ID 1000(레벨)과 2000(팔라딘)은 세로 스택으로 묶고 두 열 사이 간격을 28px로 유지합니다. - 위치 ID 3000~8000의 6개 열은 슬라이드 탐색 영역에 배치합니다. 한 열을 기준으로 탐색하며, 인접 열의 가장자리는 페이드 영역에 일부 보일 수 있습니다. - ID 7000(전투 스킬(액티브))과 8000(전투 스킬(패시브))은 기본 행 없이 추가 행 버튼만 표시합니다. - 행 추가 버튼은 위치 ID 1000~2000 및 7000~8000에 표시합니다. ID 3000~6000에는 표시하지 않습니다. ## 입력·추가·삭제 - 값 입력은 숫자뿐 아니라 퍼센트 기호와 텍스트를 입력할 수 있도록 일반 텍스트 입력을 사용합니다. 구분 이름 입력과 입력값은 텍스트 선택 및 복사가 가능해야 합니다. - 일반 열의 추가 행은 구분 이름 텍스트 입력, 적용 형식 선택 목록, 값 입력, 삭제 버튼으로 구성합니다. - ID 7000 및 8000의 추가 행은 구분 이름 대신 선택 목록을 사용합니다. 목록은 `data-model.js`의 `sectionTable` 중 ID가 3000보다 큰 항목을 ID 오름차순으로 사용하며, 값은 구분 ID입니다. - 적용 형식 선택 목록은 `applicationTable`의 모든 항목을 표시 이름으로 보여주고 선택값으로 적용 ID를 사용합니다. - 행 추가 시 행 높이와 투명도가 전환되고 삭제 버튼이 페이드인합니다. 하단의 `+` 버튼은 문서 흐름에 따라 함께 이동합니다. - 추가 행을 삭제할 때 오른쪽 입력값이 비어 있지 않으면 `(오른쪽 입력값 내용) 삭제하시겠습니까?`를 확인합니다. 비어 있으면 확인 없이 삭제합니다. 취소하면 행과 입력값을 유지합니다. - 삭제가 확정되면 행이 높이와 투명도를 줄이며 접히고, X 버튼은 별도로 페이드아웃한 뒤 DOM에서 제거됩니다. - `prefers-reduced-motion: reduce` 설정에서는 해당 애니메이션을 생략하거나 줄입니다. ## 추가 행 드래그 및 위치 간 이동 - 사용자가 추가한 행만 드래그할 수 있으며 기본 행은 이동할 수 없습니다. 별도 핸들 없이 추가 행의 영역에서 드래그를 시작합니다. - 같은 위치 안에서 이동하면 구분 이름, 적용 형식, 값 입력을 모두 유지합니다. - 다른 위치로 이동하면 `입력 값만 이동됩니다.`라는 확인 메시지를 표시합니다. 확인 시 오른쪽 값 입력만 유지하고 구분 이름과 적용 형식을 초기화합니다. - 이동을 취소하거나 유효한 대상 밖에서 드래그를 끝내면 원래 위치와 모든 입력값을 복원합니다. - 드래그 중에는 원본 행 대신 placeholder가 레이아웃 공간을 차지하며, 복제 행이 포인터를 따라갑니다. 대상 그룹 강조와 placeholder는 드래그 종료 또는 취소 시 정리합니다. ## 슬라이드 탐색 - 슬라이드 대상은 위치 ID 3000~8000의 6개 열이며, 페이지 점도 열 순서에 맞춰 6개 표시합니다. - 좌우 화살표는 각각 한 열씩 이동합니다. 첫 열에서는 왼쪽 화살표를 `‖` 모양으로, 마지막 열에서는 오른쪽 화살표를 `‖` 모양으로 바꾸어 끝 페이지임을 표시합니다. 경계 상태의 화살표는 이동하지 않으며 계속 표시됩니다. - 뷰포트에서 시작한 수평 포인터 이동이 45px 이상이고 수평 이동이 수직 이동보다 뚜렷할 때 열을 이동합니다. 입력 필드, 선택 목록, 버튼 등에서 시작한 동작은 슬라이드로 처리하지 않습니다. - 페이지 점을 누르면 해당 열로 이동합니다. 대상 열의 실제 레이아웃 위치를 사용해 이동하므로 열 너비와 간격을 이동 계산에 반영합니다. - 기본 전환 시간은 300ms이며, 여러 열을 건너뛸 때도 전체 전환 시간 기준을 유지합니다. 동작 감소 설정에서는 전환 애니메이션을 생략합니다. ## 화면 배치 및 반응형 규칙 - 800×800px 고정 크기의 `.table-content-box` 래퍼는 사용하지 않습니다. 입력 테이블 콘텐츠는 `body` 안에 직접 배치합니다. - `h1`은 저장/불러오기 버튼과 다크모드 버튼 사이에서 기존보다 오른쪽으로 10px 이동하고, Y 좌표를 기존보다 10px 아래로 표시합니다. 글자 크기는 26px, 굵기는 600이며 장식선은 표시하지 않습니다. 제목 너비를 실제 측정하여 325px 이상에서는 `마비노기 모바일 계산기`를 한 줄로, 210px 이상 325px 미만에서는 `마비노기` / `모바일 계산기`를 두 줄로, 210px 미만에서는 `마비노기` / `모바일` / `계산기`를 세 줄로 표시합니다. 제목 단어 요소가 줄 배치에 따라 이동할 때 280ms 모션을 적용하고, 동작 감소 설정에서는 생략합니다. - `.table-area`는 페이지 너비를 사용하고 콘텐츠 묶음을 가로 중앙에 정렬합니다. `.level-paladin-stack`과 `.column-carousel`은 가능한 경우 가로로 나란히 배치하며, 두 묶음과 지정된 바깥 여백을 포함한 너비가 부족하면 자동으로 다음 줄에 배치합니다. - `.level-paladin-stack`은 좌우 margin 50px, `.column-carousel`은 좌우 margin 50px을 사용합니다. 두 콘텐츠 사이에서는 스택의 오른쪽 margin과 캐러셀의 왼쪽 margin이 서로 맞닿도록 합니다. 줄이 바뀔 때는 80px의 세로 간격을 둡니다. - 페이지 제목은 콘텐츠 박스 바깥에 두고, 제목의 장식선은 표시하지 않습니다. ## 테마 및 상단 버튼 - 테마 전환 버튼은 우측 상단에서 20px 떨어진 50×50px 고정 위치에 표시합니다. 초승달과 태양 아이콘을 사용하며, 버튼 상태에 따라 아이콘과 접근성 레이블을 바꿉니다. - 쿠키 `darkmode`에 `true` 또는 `false`를 저장합니다. 쿠키가 없거나 `true`가 아니면 라이트모드로 시작합니다. 유효 기간은 315360000초이며 경로는 `/`, SameSite는 `Lax`입니다. HTTPS에서는 Secure 속성을 추가합니다. - 테마 상태에 따라 `body[data-theme]`, `aria-pressed`, `aria-label`, `title`을 갱신합니다. - 저장/불러오기 버튼은 왼쪽 상단에서 20px 떨어진 위치에 가로로 배치하고 버튼 사이 간격은 15px입니다. 다크모드 버튼은 기존처럼 오른쪽 상단에서 20px 떨어진 위치를 유지합니다. 제목은 두 버튼 사이의 가용 공간을 사용하며, 화면 너비가 줄어 제목 문구 전체가 한 줄에 들어가지 않으면 단어별로 줄을 바꿉니다. - 저장 버튼은 현재 화면의 입력 상태를 `localStorage`에 기록합니다. 입력 변경만으로 자동 저장하지 않습니다. - 불러오기 버튼은 자동 실행되지 않습니다. 사용자가 누르면 저장 기록과 버전을 검증한 뒤, 현재 입력 데이터가 모두 저장 기록으로 대체된다는 확인 팝업을 표시합니다. 취소하면 현재 화면을 유지합니다. - 저장 및 불러오기는 JSON 파일 다운로드·불러오기와 별개의 기능입니다. localStorage는 현재 브라우저의 해당 사이트 출처에 저장되며 서버나 다른 기기와 동기화되지 않습니다. - 저장/불러오기 오류는 원인을 설명하는 팝업으로 안내합니다. 상세 동작과 버전 규칙은 `readme_files/README_storage-manager.js`에서 관리합니다. - 버튼 터치 시 브라우저 기본 파란색 탭 하이라이트를 표시하지 않으며, 키보드 `:focus-visible` 표시를 유지합니다. ## 관련 파일 및 유지 조건 - `pages_js/data-model.js`: 위치·속성·구분·적용 데이터 - `pages_js/table.js`: 열·행 생성, 추가·삭제, 드래그, 슬라이드 탐색 - `pages_js/storage-manager.js`: 수동 저장 및 불러오기 - `pages_css/table.css`: 레이아웃, 테마, 색상 및 애니메이션 - `readme_files/README_storage-manager.js`: 저장 데이터 구조, 버전 관리, 오류 처리 요구사항 HTML 구조나 테마 상태 처리를 수정할 때는 테이블 스크립트와 CSS 선택자, 쿠키 복원 동작, 기존 입력값 보존에 미치는 영향을 함께 확인합니다. JSON 파일 기능과 localStorage 기능은 별개의 저장 방식으로 관리합니다.
