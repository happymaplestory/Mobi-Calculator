# table.html 요구사항 ## 역할 마비노기 모바일 계산기의 위치 기반 게임 데이터 입력 테이블을 표시합니다. 데이터 분류는 `pages_js/data-model.js`에서 관리하고, 화면 생성은 `pages_js/table.js`, 시각적 표현은 `pages_css/table.css`에서 관리합니다. ## 화면 구성 - 위치 Table의 각 항목을 하나의 category-column으로 표시합니다. - category-column은 위치 ID 오름차순으로 배치합니다. - 각 category-column의 제목은 위치 Table의 `name` 값을 사용합니다. - 각 category-group에는 위치 항목이 참조하는 속성 그룹에 속한 구분 Table 항목을 행으로 표시합니다. - 속성 Table의 `name` 값은 화면에 표시하지 않습니다. - 각 행은 첫 번째 열에 구분 Table의 `name`, 두 번째 열에 적용 기호, 세 번째 열에 사용자 입력 영역을 배치합니다. - 현재 ID 1000, 2000, 3000, 4000, 5000, 6000의 두 번째 열은 구분 Table의 적용 형식과 관계없이 `+`로 고정합니다. - ID 7000과 8000의 행 구성은 별도 지시가 있을 때까지 제목만 표시합니다. - 위치 Table의 항목을 추가하거나 삭제할 수 있는 기능은 현재 구현 범위에 포함하지 않습니다. - 화면 너비가 바뀌어도 category-column의 배치 순서와 열 구성을 자동으로 재계산하지 않습니다. 좁은 화면에서는 가로 스크롤로 확인합니다. ## 입력 영역 - 세 번째 열은 사용자가 직접 값을 입력할 수 있는 텍스트 입력 영역입니다. - 숫자뿐 아니라 `%` 및 필요한 텍스트를 입력할 수 있도록 `input type="text"`를 사용합니다. - 입력값은 텍스트 선택 및 복사가 가능해야 합니다. ## 데이터 참조 규칙 - `table.js`는 `data-model.js`의 `MOBI_DATA_MODEL`을 참조합니다. - 위치 항목은 `locationTable`의 ID, 이름, `attributeGroups`를 사용합니다. - 구분 항목은 `sectionTable`의 `id`, `group`, `name`을 사용합니다. - 행은 위치 항목이 참조하는 속성 그룹에 해당하는 구분 항목을 모아 구분 ID 오름차순으로 표시합니다. - 입력값을 계산에 사용하거나 JSON으로 저장하는 기능은 이 변경에 포함되지 않습니다. ## 관련 파일 - `table.html`: 데이터 모델과 화면 스크립트 연결 - `pages_js/data-model.js`: 위치·속성·구분·적용 데이터 정의 - `pages_js/table.js`: 위치별 열과 행 생성 - `pages_css/table.css`: 레이아웃 및 시각적 표현
