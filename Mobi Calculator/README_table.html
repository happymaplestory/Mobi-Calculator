# table.html 요구사항 ## 역할 마비노기 모바일 계산기의 게임 데이터 입력 테이블을 표시하는 실제 페이지입니다. 입력 항목의 UI와 사용자 조작을 제공하며, 항목의 목록과 세부 동작은 `table.js`, 시각적 표현은 `table.css`에서 관리합니다. ## 화면 구성 - 각 대분류는 하나의 둥근 모서리 사각형 박스로 묶어 표시합니다. - 대분류 이름은 해당 박스의 최상단에 한 번만 표시합니다. - 대분류 박스는 페이지의 가로 공간에 따라 가능한 경우 가로로 배치하고, 공간이 부족하면 다음 줄로 자동 배치합니다. - 각 대분류 안에서 필수 항목과 선택 항목을 구분하여 표시합니다. - 필수 항목과 선택 항목의 입력 열은 같은 대분류 내부에서 가로 위치가 일정하게 유지되어야 합니다. ## 필수 항목 - 필수 항목은 소분류 이름을 일반 텍스트로 표시합니다. - 대분류 이름을 각 항목마다 반복하여 표시하지 않습니다. - 필수 항목에는 삭제 버튼을 제공하지 않습니다. - 필수 항목에는 값을 입력할 수 있는 입력 영역을 제공합니다. ## 선택 항목 - 선택 항목은 소분류를 드롭다운으로 선택합니다. - 선택 항목에는 값을 입력할 수 있는 입력 영역을 제공합니다. - 선택 항목에는 삭제 버튼을 제공합니다. - 선택 항목에는 대분류 드롭다운을 제공하지 않습니다. - 각 대분류의 최하단에 선택 항목 추가 버튼을 제공합니다. - 선택 항목의 값이 비어 있지 않은 상태에서 삭제하면 삭제 여부를 확인합니다. - 같은 소분류를 여러 번 추가할 수 있습니다. - 같은 소분류가 여러 개 존재하는 경우 소분류 이름 뒤에 추가된 순서에 따라 번호를 표시합니다. 예: `확률 % (1)`, `확률 % (2)`. ## 소분류 및 대분류 이동 - 선택 항목의 소분류 목록은 현재 대분류에 따라 달라집니다. - 선택 항목은 같은 대분류 안에서 드래그 앤 드롭으로 순서를 변경할 수 있습니다. - 드래그 중인 선택 항목은 마우스 커서를 따라 이동합니다. - 드래그하여 놓을 위치에는 해당 항목이 들어갈 공간을 표시합니다. - 드래그 중 주변 선택 항목은 이동 위치에 따라 자연스럽게 이동합니다. - 선택 항목을 다른 대분류 박스로 이동하여 놓으면 다음 확인 문구를 표시합니다. `다른 목차로 이동 시 종류 구분이 초기화됩니다. 진행하시겠습니까?` - 다른 대분류로 이동할 때 취소하면 선택 항목은 원래 위치로 복원합니다. - 다른 대분류로 이동할 때 확인하면 값 입력 영역의 데이터만 유지합니다. - 다른 대분류로 이동할 때 소분류는 대상 대분류의 첫 번째 선택 항목으로 초기화합니다. ## 입력 영역 및 열 너비 - 드롭다운의 텍스트가 잘리지 않도록 필요한 가로 공간을 확보합니다. - 필수 항목과 선택 항목이 존재하거나 추가되는 것에 관계없이 같은 세로 열의 가로 위치가 변하지 않도록 열 너비를 고정합니다. - 열 너비는 현재 데이터에 포함된 가장 긴 텍스트를 기준으로 계산합니다. - 드롭다운의 내부 여백과 선택 표시 영역에 필요한 추가 공간을 고려합니다. - 값 입력 영역의 텍스트는 선택 및 복사가 가능해야 합니다. ## UI 상호작용 - 입력 영역을 제외한 항목과 버튼은 마우스 드래그 또는 터치 길게 누르기로 텍스트를 선택하거나 복사할 수 없도록 합니다. - 각 입력 항목과 추가/삭제 버튼은 기본 테두리보다 두꺼운 테두리를 사용합니다. - 입력 영역을 제외한 항목과 버튼에 마우스를 올리면 해당 대분류의 기본 배경색보다 조금 진한 배경색을 표시합니다. - 대분류별로 서로 다른 계열의 배경색과 테두리색을 사용할 수 있으며, 현재 구현된 대분류의 색상은 `table.css`에서 관리합니다. ## 관련 파일 - `table.js`: 대분류, 필수 항목, 선택 항목 데이터 및 동작 관리 - `table.css`: 레이아웃과 시각적 표현 관리
