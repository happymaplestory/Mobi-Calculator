# table.html 요구사항 ## 역할 마비노기 모바일 계산기의 입력 테이블 UI를 표시하는 페이지입니다. ## 구현 요구사항 - 대분류별 입력 항목을 하나의 박스로 표시합니다. - 필수 항목은 일반 텍스트와 값 입력 영역으로 표시합니다. - 선택 항목은 소분류 드롭다운, 값 입력 영역, 삭제 버튼으로 표시합니다. - 선택 항목은 추가 및 삭제할 수 있습니다. - 선택 항목은 같은 대분류 안에서 드래그 앤 드롭으로 순서를 변경할 수 있습니다. - 선택 항목을 다른 대분류로 이동할 때 종류 구분 초기화 여부를 확인합니다. - 다른 대분류로 이동할 때 값 입력 영역의 데이터는 유지합니다. - HTML, CSS, JavaScript를 분리하여 관리합니다.
