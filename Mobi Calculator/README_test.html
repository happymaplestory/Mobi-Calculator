# test.html 요구사항 ## 역할 프로젝트의 실제 기능 개발에 앞서 웹페이지의 동작과 UI를 외부 환경에서 확인하기 위한 개발 테스트 페이지입니다. GitHub Pages를 통해 외부에서 접근할 수 있으며, 다른 실제 페이지에 기능을 반영하기 전에 HTML, CSS, JavaScript 및 브라우저 동작을 테스트하는 용도로 유지합니다. ## 현재 테스트 범위 현재 테스트 페이지에서는 게임 데이터 입력 항목의 기본적인 추가, 삭제 및 분류 변경 동작을 검증합니다. - PC 화면을 우선 기준으로 구현합니다. - 입력 항목은 모서리가 둥근 사각형 형태의 UI를 사용합니다. - 필수 항목은 대분류와 소분류를 일반 텍스트로 표시하고 삭제 버튼을 제공하지 않습니다. - 선택 항목은 대분류와 소분류를 드롭다운으로 선택하며 삭제 버튼을 제공합니다. - 선택 항목의 값이 비어 있지 않은 상태에서 삭제하면 확인 팝업을 표시합니다. - 선택 항목은 각 대분류의 최하단 `+` 버튼으로 추가합니다. - 선택 항목의 대분류를 변경하면 해당 대분류의 항목 목록 최하단으로 이동합니다. - 소분류 목록은 대분류에 종속됩니다. - 드롭다운의 텍스트가 잘리지 않도록 항목의 필요한 가로 공간을 확보합니다. - 필수 항목과 선택 항목이 존재하거나 추가되는 것에 관계없이 같은 세로 열의 가로 위치가 변하지 않도록 대분류와 소분류 열의 너비를 전체 테스트 데이터 기준으로 고정합니다. - 대분류와 소분류 열의 고정 너비는 테스트 데이터에 포함된 가장 긴 텍스트를 기준으로 계산하며, 드롭다운의 내부 여백과 선택 표시 영역을 위한 추가 공간을 포함합니다. - 테스트 데이터 목록은 `test-data.js`에서 별도로 관리합니다. - 각 대분류의 항목은 하나의 둥근 모서리 사각형 박스로 묶어 표시합니다. - 대분류 박스는 페이지의 가로 공간에 따라 가능한 경우 가로로 배치하고, 공간이 부족하면 다음 줄로 자동 배치합니다. ## 현재 테스트 데이터 - 대분류: 공격력, 치명타 - 공격력 소분류: 공격력 %, 공격력 + - 치명타 소분류: 치명타 %, 치명타 +, 치명타 데미지 %, 치명타 확률 % 초기 화면에는 다음 6개의 필수 항목을 표시합니다. - 공격력 / 공격력 + - 공격력 / 공격력 % - 치명타 / 치명타 + - 치명타 / 치명타 % - 치명타 / 치명타 데미지 % - 치명타 / 치명타 확률 % ## 유지 정책 이 파일과 `README_test.html`은 일회성 GitHub Pages 접속 확인용 임시 파일이 아니라, 프로젝트 개발 과정에서 지속적으로 사용하는 개발 테스트 페이지로 유지합니다. 새로운 테스트가 필요할 때 기존 테스트 내용을 수정하거나 추가하여 사용하며, 별도의 실제 페이지를 만들기 전에 이 페이지에서 동작을 검증할 수 있습니다.
